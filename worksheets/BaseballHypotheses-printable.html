    Worksheet Understanding Hypothesis Testing
    

    Objectives

    • Understand what the \(p\)-value really is.
      🔗
      🔗
    • Replicate sample from a known population to see how far off using a \(t\)-test can be when its hypotheses are not satisfied.
      🔗
      Do some data wrangling to do a paired \(t\)-test that is reasonably accurate.
      🔗
      🔗
    🔗
    In this activity we will try to gain a deeper understading of using \(t\)-tests to test hypotheses about the mean. We will do this by looking at home runs in Major League baseball. We are using this data for several reasons. First, we have access to the population data. Second, home run data does not really fit the hypotheses of the \(t\)-test. Finally, we can get some practice data wrangling so the the \(t\)-test is acceptable.
    🔗

      🔗
      🔗
    • Extract the \(p\)-value using test$p.value and get a TRUE or FALSE value depending on whether or not \(p\) is less than \(0.05\text{.}\)

    • (1 points) Is the null hypothesis true?
      🔗

    Definition 1. Type I Error.

    Type I error is rejecting the null hypothesis when it is true. When we set a significance level, \(\alpha\text{,}\) we are setting an acceptable probability of type I error. In a properly constructed \(t\)-test, when the null hypothesis is true, we will commit a type I error \(\alpha\times 100 \%\) of the time.
    🔗
    🔗
    Now we will consider how the probability of type I error can be far off from what it is supposed to be by considering home run data.
    🔗

    Definition 2. Type II Error.

    Type II error is failing to reject the null hypothesis when it is false. The probability of type II error is typically denoted by \(\beta\text{.}\) The probability of correctly rejecting the false null hypothesis is \(1-\beta\text{,}\) and is called the power.
    🔗
    🔗

    5.

    Now create two new data sets that consist of seasons with yearID from 1994 to 2004, and after 2004, respectively (these are the "steroid" and "post-steroid" eras). Filter further to only include hitters with more than \(100\) at bats (AB). Create a new variable in each data set that is rate=HR/AB.
    🔗

    (a)

    (3 points) Perform a two sample \(t\)-test, on a random sample of 200 players from each era, to test whether players in the steroid era had a significantly different HR rate. (By finding the mean HR rates from each era we can tell the null hypothsis is false.)
    🔗
    🔗

    (b)

    (2 points) Now replicate the above test \(10000\) times to estimate the type II error rate. What is the power of this two sample \(t\)-test?
    🔗
    🔗
    This is a situation where the only practical way to increase the power of the \(t\)-test is to use a very large sample (here, one that is close to the full population). This is because the effect of era on HR rate is small compared to the substantial variability due to other factors, such as player ability and playing time. As a result, although the \(t\)-test is valid, strong conclusions based on a modest sized sample may not be advised. In contrast, in situations where the variable being tested is a primary source of variation, a \(t\)-test based on a smaller sample may yield more conclusive results.
